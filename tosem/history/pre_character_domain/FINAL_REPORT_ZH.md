## 本轮实际修复

**标量与列表表示一致。** 空条件字符串与包含该字符串的单元素列表采用相同语义；空列表仍不被接受。显式策略版本不能省略，策略 Id / 语句 Sid 与来源引用需要正确字符串类型。

**正向检查与原发行者模型一致。** 显式 subject 模式是对类型化发行者语言的限制，而不是替换该语言；正向路径现在同时遵守 subject 与 audience 限制。空限制列表保持原核心默认含义。不可铸造或不符合契约的正向身份返回 unknown，不误报成部署回归。

**确定的通配符语义与耗尽状态。** 正向匹配使用两行动态规划；只有星号和问号是通配符，括号、反斜杠等按字面处理。每次通配符匹配设 2,000,000 单元工作上限，并共享审查的单调时钟预算。耗尽返回 unknown，不转成 pass 或确认违规。字面相等采用独立快路径；没有宣称能够硬实时抢占所有解析、分配或宿主执行。

**时间与重放边界。** 只有省略时间参数才读取当前时间；空字符串、False、零等显式非法输入不再偷偷选择当前时钟。四份快照共同有效的时间区间为 `[max(s_i), min(s_i+tau)]`，含端点；无交集时不存在共同有效时刻。重放仍重新计算双向结论，完整绑定发布契约、必需身份、输入与实现依赖；一致重放的 fail/unknown 不成为 pass。

**构建与审计。** 修正跨页代码示例、重复公式标签及环境中的 BibTeX 可执行文件选择。生成图表直接绑定实测 CSV；审计重新计算中位数、最小/最大值，逐点检查绘图数据和输出 PDF 摘要。复现禁止关闭 Python 断言。
