# FSE 2027 final evidence gates

The final package separates **submission-package completeness** from **external
validation**. The former is complete and audited; the latter is deliberately not
claimed.

| Gate | Final status | Interpretation |
|---|---|---|
| Software-engineering problem | Complete | CI/CD trust is framed as cross-artifact configuration evolution and change impact |
| Formal/semantic revision | Complete for stated model | Must-safe observations, two-sided conformance, tuple-level Deny, minimal vs. minimum basis clarified |
| Developer workflow | Packaged | CLI, JSON/SARIF/GitHub outputs, schema, composite action, reference PR workflow |
| Local semantic consistency | Complete locally | 79 tests, 65,536 finite models, 37 historical cases, 3,945 inherited self checks |
| Executable examples | Complete locally | Eight walkthroughs cover pass/fail/unknown and security/availability regressions |
| Before/after source evidence | Complete for frozen pilot | 17 candidates screened, 9 included, all source snapshots and phase directions checked |
| Runtime-maintenance evidence | Complete for frozen purposive corpus | 12 commits; 11 report broken/denied exchanges; two public post-fix success run IDs |
| Source-normalization frontier | Complete for frozen convenience sample | 24 repositories; 7 literal/constant-foldable, 17 require evaluation |
| Manuscript/artifact consistency | Complete locally | Final audit, PDF preflight, 12-page ACM review manuscript |
| Representative prevalence | Not claimed | Requires probability or otherwise justified sampling |
| Independent intent labels | Not claimed | Requires blinded second annotation or owner confirmation |
| Vendor common-corpus comparison | Not performed | Zero product runs are explicitly recorded |
| Live FedFence deployment | Not performed | Reference action is packaged but not externally installed |
| Human effort/usability | Not measured | Requires appropriate study/ethics process |
| Machine-checked refinement | Not present | Proof-to-code boundary remains explicit |

## Submission claims supported

- The gate implements pass/fail/unknown for its stated fragment.
- It distinguishes admission expansion from finite required-identity loss.
- Results bind policy, issuer, workflow, governance, contract, and implementation
  dependencies and replay the certificate.
- Public changes and maintenance commits demonstrate source-level applicability and
  recurring provider-format drift.
- The 24-source sample demonstrates why a sound field study needs plan/module/
  synthesis evaluation rather than simple grep-based extraction.

## Claims intentionally withheld

- prevalence, precision/recall, or representative fragment coverage;
- maintainer-confirmed vulnerabilities discovered by FedFence;
- causal attribution from a trust edit to a successful workflow;
- superiority over adjacent tools;
- production deployment readiness or human productivity; and
- end-to-end cloud security beyond role admission.
